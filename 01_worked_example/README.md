# Framework implementation example - CLT kitchen-floor scenario.
This folder contains a framework implementation example for a CLT kitchen-floor system. The implementation example demonstrates how the framework layers can be used to move from moisture-risk identification to sensor deployment, monitoring-record definition, interpretation, and later reuse-related assessment.

The implementation example is intended as a guide only. It does not prescribe universal sensor spacing, fixed moisture thresholds, or standardised layouts. Users should adapt the approach to the project-specific building design, moisture risks, monitoring objectives, sensor system, and decision context.

## Folder contents
- `clt_kitchen_floor_application.md` 
Framework implementation example showing how the framework can be applied to appliance zones, panel junctions, fastener areas, and floor-wall junctions in a CLT kitchen floor.
