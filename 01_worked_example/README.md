# Worked example - CLT kitchen-floor application.
This folder contains an illustrative application of the framework to a CLT kitchen-floor system. The example demonstrates how the framework layers can be used to move from moisture-risk identification to sensor deployment, monitoring-record definition, interpretation, and later reuse-related assessment.

The example is intended as a guide only. It does not prescribe universal sensor spacing, fixed moisture thresholds, or standardised layouts. Users should adapt the approach to the project-specific building design, moisture risks, monitoring objectives, sensor system, and decision context.

## Folder contents
- `clt_kitchen_floor_application.md` 
Worked example showing how the framework can be applied to appliance zones, panel junctions, fastener areas, and floor-wall junctions in a CLT kitchen floor.
