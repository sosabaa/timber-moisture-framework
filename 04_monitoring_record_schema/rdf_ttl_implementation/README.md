# RDF Turtle implementation

This folder contains a Turtle serialization of the compact monitoring-record graph. It is intended for users who want to inspect or load the model with RDF tools, ontology editors, SPARQL engines, or triple stores.

## Files

- `monitoring_record_schema_example.ttl`
  RDF/Turtle representation of the compact JSON-LD monitoring-record example.

The JSON-LD implementation remains the primary authoring format for the repository. The Turtle file provides an RDF-native view of the same semantic structure.
