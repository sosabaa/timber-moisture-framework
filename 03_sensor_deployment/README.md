# Sensor deployment guide

This folder contains a template for translating moisture-risk classification into practical sensor-deployment decisions. It supports decisions on sensor type, placement, measurement depth, density, redundancy, reference locations, protection, access, and validation.

The template is intended to be used after the risk-location classification step. It does not prescribe universal sensor spacing, fixed sensor numbers, or standardised layouts. Sensor deployment should be adapted to the project-specific moisture risks, timber assembly, sensor system, monitoring objective, access conditions, and intended decision use.

## Folder contents

- `sensor_deployment_template.md`  
  Template for documenting practical sensor implementation decisions for each classified moisture-risk location.
